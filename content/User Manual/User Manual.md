# Introduction

ResuMint is an Artificial Intelligence powered recruitment platform developed to improve recruitment efficiency for recruiters while helping candidates build stronger, more competitive resumes.

The platform combines resume analysis, intelligent candidate evaluation, job matching, and interview preparation into a unified recruitment experience.

---

# About ResuMint

ResuMint assists two primary groups of users:

- Candidates
- Recruiters

The platform enables candidates to improve their employability while providing recruiters with intelligent tools for identifying qualified applicants.

---

# Purpose of the Platform

ResuMint is designed to:

- Improve resume quality.
- Match candidates with suitable job opportunities.
- Reduce manual recruitment effort.
- Improve hiring accuracy.
- Assist candidates with interview preparation.
- Support fair and transparent recruitment.

# System Requirements

Users should have:

- Stable internet connection
- Supported web browser
- Valid email address
- Resume in PDF or DOCX format
- Desktop, laptop, tablet or smartphone

---

# Accessing ResuMint

Before using the platform users must:

1. Create an account.
2. Verify their email.
3. Log in.
4. Select the appropriate user role.

If account access is lost, use the Forgot Password feature.

# Navigating the Platform

After authentication, users are directed to a dashboard based on their account type.

- Job Search

Provides access to:

- Job Management
- Candidate Review

- Shortlisting

# Artificial Intelligence Features

ResuMint uses Artificial Intelligence throughout the recruitment process.

Key AI capabilities include:

Smart Semantic Scan

Compares resumes against job requirements to determine candidate suitability.

Candidate Job Fit

Calculates how closely candidates match available vacancies.

Explainable Scores

Provides a detailed explanation of candidate evaluation instead of displaying only a single score.

Micro-Assessments

Generates targeted screening questions that help recruiters validate candidate knowledge.

Resume Improvement Suggestions

Provides personalized recommendations for improving resumes.

Interview Question Generation

Creates interview questions based on resume content and job requirements.
