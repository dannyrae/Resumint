# Resumint 

> Helping new graduates and early-career professionals find opportunities, create tailored resumes and connect with the right recruiters who hire talents. Together building a secured Future.

---

## Overview

Resumint is an intelligent recruitment platform that enables job seekers to create customised resumes for every job application using AI. Instead of sending the same resume to every employer, the platform analyses job descriptions and generates tailored resumes that highlight the applicant's most relevant skills, education, and experience.

The platform also matches candidates with recruiters and employers based on skills, qualifications, career interests, location, and job preferences, increasing the chances of securing interviews and employment.

---

## Problem Statement

Many entry-level job seekers struggle because:

- They use one generic resume for every application.
- They lack experience writing ATS-friendly resumes.
- They find it difficult to discover recruiters actively hiring.
- Recruiters receive thousands of applications that are poorly matched to job requirements.

Resumint bridges this gap using Artificial Intelligence.

## Features

### AI Resume Tailoring

- Analyses job descriptions.
- Creates ATS-friendly resumes.
- Highlights relevant skills and achievements.
- Optimises keywords for applicant tracking systems.

### Resume Rating

Provides a compatibility rate showing how well the resume matches a specific job posting.

### Cover Letter Generator

Creates personalised cover letters based on:

- Job description
- Candidate profile
- Employer information

### Recruiter Matching

Matches candidates with recruiters based on:

- Skills
- Qualifications
- Industry
- Career goals
- Location
- Salary expectations

### Job Recommendations

Uses AI to recommend relevant jobs based on the user's profile.

### Recruiter Dashboard

Recruiters can:

- Search candidates
- Filter applicants
- Review AI-generated compatibility scores
- Contact shortlisted candidates

### Candidate Dashboard

Candidates can:

- Manage resumes
- Track applications
- Receive recruiter invitations
- Monitor resume performance

### Notifications

Receive alerts when:

- A recruiter views your profile.
- A new matching job becomes available.
- Your application status changes.

## Installation

Clone the repository.

```bash
git clone https://github.com/yourcompany/resumint.git
```

Navigate into the project.

```bash
cd resumint
```

Install dependencies.

```bash
npm install
```

Run the application.

```bash
npm run dev
```
